# AI Learning Labs

Static, dependency-free study labs with browser-local progress. Open `index.html` directly for simple use, or serve the `learning-labs` folder with any static web server.

- `aitech-mastery/` — AI Technical Practitioner Mastery Lab: 73 adaptive concept and scenario drills.
- `agentic-masterclass/` — Agentic AI Masterclass Systems Lab: 62 chapter-aligned drills.

Each lab keeps XP, streaks, topic mastery, badges, and its recovery queue in the browser's local storage. No answers, prompts, or user data are sent to a server.

For GitHub Pages, publish the contents of `learning-labs/` as the site root. The root `index.html` links both apps.
